A troca vale para todos os produtos de uma vez (sistemas externos podem levar até 1 dia para atualizar a imagem já guardada).

          Desligado: a API responde a qualquer sistema, e as consultas feitas com a chave de uma empresa são contadas para a cobrança dela. Ligado: a API (/api/v1/… e /img/…) só responde com a chave de uma empresa ativa. Antes de ligar, confira se todos os sistemas que consultam o catálogo já enviam a chave.
